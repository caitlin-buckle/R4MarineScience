# R For Marine Science 
This repository is for the code from Module 2, R for Marine Science. We continued to advance our visualisation skills in R, and focused on the importance of data cleaning and processing prior to analysis. Our keystone activity had us cleaning a messy dataset on catch data from four fish species across a salinity gradient. Our final activity was to use our skills to find a published plot with visualisation issues, and recreate this plot with solutions to the identified problems. 

 
## Folder and File Description 
/code --> .Rmd and .Qmd files for each workshop/activity 

/data --> all data used for each workshop. Note, the data from workshop 3 was sourced using plotdigitiser.com from Reid et al. (2011) 'Decadal trends in shark catches and effort from the New South Wales, Australia, Shark Meshing Program 1950–2010' paper 

/output --> rendered .png images of plots created in first two workshops 
      
/Catches Per Beach.png --> recreated plot fixing visualisation issues seen in Reid et al. (2011)
